# 订单与文档实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans，继续当前会话实现。

**目标：** 让客户关联多商品订单，生成可打印报价，并在公司空间内管理文档和模板。

**架构：** 独立订单/商品/文档库/文件/模板表，全部绑定空间；金额以 Decimal 计算后保存字符串，未知数量/单价仍保持为空。文件名由服务端生成，文件下载前核对空间；原文件保留在应用数据目录。报价 HTML 对全部业务文本转义。

- [x] 失败测试：多商品合计、待谈金额、负数/非有限数拒绝、合法状态迁移、跨账号订单和客户绑定拒绝、报价文本转义。
- [x] 实现订单仓储、API 与报价 HTML。
- [x] 失败测试：文档上传/下载隔离、文件大小限制、库归属、模板隔离、可解析文本读取、所选文档对话上下文。
- [x] 实现生成路径的上传存储、库和模板 API；扫描 PDF/图片不伪称已识别。
- [x] 接中文订单/文档/模板页面、表单和文件下载；退出后清空页面与异步请求。
